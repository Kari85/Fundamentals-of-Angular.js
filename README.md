# Fundamentals of Angular.js

This repository contains small JavaScript and TypeScript exercises.

## Industrial connectivity feature notes

The following topics outline common building blocks for an industrial Angular dashboard or monitoring application:

- **MQTT**: Lightweight publish/subscribe messaging for receiving telemetry from sensors, gateways, and edge devices.
- **Modbus**: Fieldbus protocol support for reading values from PLCs, meters, and other industrial equipment.
- **WebSocket**: Browser-friendly real-time channel for pushing live measurements and state changes to the user interface.
- **Grafiikat**: Charts, trend views, and visual status indicators for presenting process values clearly.
- **Hälytykset**: Alarm handling for threshold breaches, device faults, acknowledgement workflows, and operator notifications.
